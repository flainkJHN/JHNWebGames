Most modern computers are designed using Von Neumann Architecture. However, in some cases Harvard Architecture may be preferred.

Discuss the difference between Von Neumann Architecture and Harvard Architecture.

You should refer to:

  • the different approaches each architecture takes to storing instructions and data

Answer A

Von Neumann architecture stores instructions and data in the same memory and uses a single bus system. This means that instructions and data cannot be transferred at the same time. This can create a bottleneck because the CPU has to wait for access to memory.

Harvard architecture stores instructions and data in separate memories and uses separate buses for each. This allows instructions and data to be transferred simultaneously. As a result, the processor is usually faster because it can fetch an instruction while accessing data.

An advantage of Von Neumann architecture is that it is simpler and cheaper to design. Because instructions and data share the same memory, memory space can be allocated dynamically. For example, a large computer game may require a lot of memory for instructions, whereas a video editing application may require more memory for data.

An advantage of Harvard architecture is its performance. The separate memory and buses reduce delays caused by the Von Neumann Bottleneck. This makes it suitable for embedded systems, digital signal processors and microcontrollers where speed is important.

Overall, although Harvard architecture offers greater performance because it allows parallel access to data and instructions, Von Neumann architecture is generally preferred for modern computers because it is less complex, cheaper to implement and uses memory more flexibly.

Answer B

Von Neumann and Harvard architectures store instructions and data differently. Von Neumann stores instructions and data together in the same memory, while Harvard uses separate memories.

Harvard architecture can be faster because it can access instructions and data at the same time. Von Neumann computers may experience a bottleneck because they use one bus.

Von Neumann architecture is cheaper and simpler to build. Harvard architecture is more complex because it needs additional buses and separate memory.

Overall, Harvard architecture is good when speed is required, while Von Neumann architecture is useful because it is simpler and cheaper.
