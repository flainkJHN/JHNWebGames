CPU Performance Factors

Clock Speed

The number of Fetch-Decode-Execute (FDE) cycles a CPU can complete in one second. Measured in GHz.
Number of Cores

A core is a processing unit inside the CPU. More cores allow the CPU to work on more tasks simultaneously.
Cache Size

Cache is very fast memory inside the CPU. A larger cache means instructions and data can be accessed more quickly.
